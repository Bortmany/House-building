# House-building estimator

One HTML file. Enter a house (floors, rooms, wall height), get how many concrete blocks, how much
rebar steel and how much ready-mix concrete it needs, with editable OMR prices.

The same page also tells the story of how it was built by an AI agent team, step by step.

Open `index.html` in any browser. To rebuild after changing `src/`: `node scripts/build.mjs`.
Rules and verify recipe: `docs/CONVENTIONS.md`.
